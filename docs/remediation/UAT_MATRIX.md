# END-TO-END ROLE-BASED UAT MATRIX (Phase E, Phase B & `R34–R45` — `nexus_hrms_test`)

Ma trận nghiệm thu theo vai trò và giao diện đa khung nhìn (`390px`, `768px`, `1440px`) của hệ thống **NEXUS HRMS** trên cơ sở dữ liệu kiểm thử tách biệt `nexus_hrms_test`.
Tài liệu này phân biệt rõ:
- **Mức bằng chứng (Evidence Level)**:
  - `UI E2E (FRESH_VERIFIED)`: Trình duyệt thực Headless Chrome/Edge (CDP) với bộ lắng nghe `Runtime.exceptionThrown` gắn xuyên suốt từ đầu phiên (`ASSERT 1..12`), đa `BrowserContext` độc lập, Frontend Vite, Backend Express và PostgreSQL `nexus_hrms_test`.
  - `API/DB Integration (FRESH_VERIFIED)`: Supertest qua toàn bộ chuỗi Middleware (`authenticate`, `requirePermission`, `validate`) + Controller + Service + PostgreSQL `nexus_hrms_test`.
  - `Service/Unit (FRESH_VERIFIED)`: Kiểm thử hàm logic/adapter độc lập (`node --test`, chạy độc lập cả khi PostgreSQL không kết nối được — `R40`).
  - `STATIC_VERIFIED / ENV_BLOCKED`: Cấu hình `Dockerfile`, `docker-compose.yml`, `FrontEnd/nginx.conf` đã kiểm tra tĩnh và kiểm thử qua HTTP reverse proxy nội bộ đọc `client_max_body_size 10m;`, nhưng container Docker thực và tiến trình `nginx` native chưa chạy do máy host chưa bật Docker Desktop daemon (`ENV_BLOCKED`).
- **Phạm vi trung thực (`R45`)**: Kịch bản 12 (`ASSERT 12`) là **Route/Render, Responsive Overflow, Kiosk Terminal & Modal Keyboard/Scroll Smoke Matrix** kết hợp cùng các kịch bản chuyên sâu `ASSERT 1..11` (Settings, Directory Pagination, Payroll Calculation/Lock/CSV Reconciliation, Tasks History, AI Copilot, Company Notice Attachments & Cross-Department Notification Isolation). Không suy diễn từ tổng số test sang những tích hợp ngoài môi trường (`Live Gemini API`, `Docker daemon`, `Production DB migration`).
