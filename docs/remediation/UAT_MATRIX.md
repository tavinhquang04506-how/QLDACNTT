# END-TO-END ROLE-BASED UAT MATRIX (Phase E, Phase B & `R34–R40` — `nexus_hrms_test`)

Ma trận nghiệm thu theo vai trò và giao diện đa khung nhìn (`390px`, `768px`, `1440px`) của hệ thống **NEXUS HRMS** trên cơ sở dữ liệu kiểm thử tách biệt `nexus_hrms_test`.
Tài liệu này phân biệt rõ:
- **Mức bằng chứng (Evidence Level)**:
  - `UI E2E`: Trình duyệt thực Headless Chrome/Edge (CDP) + đa `BrowserContext` độc lập + Frontend Vite + Backend Express + PostgreSQL `nexus_hrms_test`.
  - `API/DB Integration`: Supertest qua toàn bộ chuỗi Middleware (`authenticate`, `requirePermission`, `validate`) + Controller + Service + PostgreSQL `nexus_hrms_test`.
  - `Service/Unit`: Kiểm thử hàm logic/adapter độc lập (`node --test`, chạy độc lập cả khi PostgreSQL dừng — `R40`).
- **Luồng nghiệp vụ hợp lệ (Positive Flow)** tách biệt hoàn toàn với **Kiểm thử chặn quyền (Negative Permission Test)**.
