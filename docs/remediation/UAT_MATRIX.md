# END-TO-END ROLE-BASED UAT MATRIX (Phase E & R34–R36 — `nexus_hrms_test`)

Ma trận nghiệm thu theo vai trò của hệ thống **NEXUS HRMS** trên cơ sở dữ liệu kiểm thử tách biệt `nexus_hrms_test`.
Tài liệu này phân biệt rõ:
- **Mức bằng chứng (Evidence Level)**:
  - `UI E2E`: Trình duyệt thực Headless Chrome/Edge (CDP) + Frontend Vite + Backend Express + PostgreSQL `nexus_hrms_test`.
  - `API/DB Integration`: Supertest qua toàn bộ chuỗi Middleware (`authenticate`, `requirePermission`, `validate`) + Controller + Service + PostgreSQL `nexus_hrms_test`.
  - `Service/Unit`: Kiểm thử hàm logic/adapter độc lập (`node --test`).
- **Luồng nghiệp vụ hợp lệ (Positive Flow)** tách biệt hoàn toàn với **Kiểm thử chặn quyền (Negative Permission Test)**.
